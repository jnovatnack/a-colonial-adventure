# A Colonial Adventure

A top-down, 16-bit style adventure game set in colonial New England, in the style of *A Link to the Past*.

**Chapter One · Late summer, 1774.** You're a farmer at the edge of the wood. Your wheat is failing for the third year running, and nobody at home knows why. Follow the forest path along the creek to the Plough & Harrow, the tavern at the crossroads, and ask around.

## Play

The game is a single web page (`index.html`) plus the art and map data in `world/`. Browsers won't load the data files from a page opened straight off the disk, so serve the folder locally:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

| Action | Keyboard | Touch |
| --- | --- | --- |
| Walk | Arrow keys or WASD | Drag anywhere |
| Run | Hold Shift | Drag to the edge of the stick |
| Talk, look, sit, order | E, Space or Enter | A button |
| Stand up | Walk away | Drag |
| Mute | M | Sound button |

## What's in it

- **The homestead:** farmhouse, barn, coop, well, kitchen garden, and fields of Indian corn, wheat, flax and pumpkins. Hannah, your wife, is in the garden. Ranger, your dog, follows you everywhere.
- **The forest path:** a long walk through the woods beside a creek, which bends west under a footbridge as you leave the forest.
- **The crossroads:** the Plough & Harrow tavern, with smoking chimneys, a stable with horses, and a signpost.
- **Inside the tavern:** order an ale from Mr. Hale, sit with the neighbors, and listen to the gossip.
- **The wheat mystery:** the first quest, about wheat rust and the barberry hedge.
- **Historical notes:** looking at things, and some conversations, add a short note about colonial life.
- **Sound:** all synthesized in the browser with the Web Audio API: the creek, birds, wind in the forest, chickens, the ox, the tavern fire and chatter, and footsteps.

## Project layout

```
index.html        The game: engine, dialogue, historical notes and sound (plain JavaScript, no libraries)
world/            Generated art and map data the game loads
  world.json        Map layouts: object positions, people, doors, things to look at, sound positions
  outdoor.png       Ground layer for the homestead, forest and crossroads
  tavern.png        Ground layer for the tavern interior
  *_collide.png     Collision masks (red = solid)
  objects.png       Sprite sheet for buildings, trees and props
  player.png        The farmer's walk cycle
  people.png        Hannah, the tavern keeper and the neighbors
  dog.png, chicken.png
tools/            Python scripts that draw all the pixel art and build the maps
concept-art/      Early concept scenes
```

## Editing the story

All dialogue lives near the top of the script in `index.html`:

- `TALK` holds what each person says and the descriptions of things you can look at.
- `NOTES` holds the historical notes.
- `SPECIAL` and `QUEST` hold the wheat mystery quest.

## Rebuilding the art

The art is generated by code, so new buildings, characters and maps come out in the same style. You need Python 3 with NumPy, SciPy and Pillow:

```sh
pip install -r tools/requirements.txt
cd tools
python3 game_world.py
```

This rewrites everything in `world/` and saves map previews to `build/previews/`.

- `pix.py`: drawing helpers (auto-shaded sprites from region art, trees, buildings, grass, dirt and water)
- `chars.py`, `sprites2.py`, `props.py`: characters, animals and props as hand-typed pixel art
- `game_world.py`: lays out the outdoor map and the tavern interior
